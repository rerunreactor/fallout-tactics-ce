Fallout Tactics CE for macOS (preview)
=====================================

You need your own copy of Fallout Tactics: Brotherhood of Steel 1.27.
It's sold for Windows, so you need the game's files from a Windows copy:
see "Getting the game files" below.

1. Move "Fallout Tactics CE.app" to your Applications folder, or anywhere.
2. Open it. The first time, macOS stops it, because the app isn't signed
   by a registered developer yet. To allow it:
   - open System Settings, then Privacy & Security;
   - scroll down to the line about "Fallout Tactics CE" and click
     "Open Anyway", then confirm.
   You only do this once.
3. Choose your Fallout Tactics folder: the one with the core folder in it.
   It remembers the folder after that.

If you put the app in the same folder as the game's core folder, it finds
the game by itself.


Getting the game files
----------------------
The app needs the folder that holds core, from a Windows copy of the game:

- From a Windows PC with the game installed: copy the whole Fallout
  Tactics folder to your Mac.
- From GOG: download the Windows offline installer from your GOG library
  and unpack it with innoextract (with Homebrew: brew install innoextract),
  keeping any .bin files next to the installer:
      innoextract setup_fallout_tactics_*.exe
  Then choose the folder it unpacked that contains core.
- From Steam: Steam for Mac won't install the Windows version. Copy the
  folder from a PC instead.


Saves and bug reports
---------------------
Saves go to ~/Library/Application Support/RerunReactor/Fallout Tactics CE/saves,
apart from the original game's saves. The same folder has fotgame.log, the
log of the last run: please attach it to bug reports.

To choose a different game folder, delete game-folder.txt there.


What to expect
--------------
This is a preview. The first mission plays from start to debrief.
Character creation, multiplayer, movies, barter, targeted shots and some
menus are missing. The full list:
https://github.com/rerunreactor/fallout-tactics-ce/blob/main/docs/status.md

Bugs and questions: https://github.com/rerunreactor/fallout-tactics-ce/issues

The tools folder holds mapview, sprview and sprtrim: command-line tools
for modders.
